# Changelog
 
All notable milestones in this research project.
 
## Research Milestones
 
### Milestone 4 — V2.17 (August–October 2026)
**Conjecture 14.3 (Structural Independence) — Validated Heuristic Conjecture**
 
- Theorem 3.2 proved: h*=2 for rectangular boxes (d≥2) via Dispersed Corner Decomposition
- Theorem 6.1/7.1 proved: complete d=1 classification
- Conjecture M3' verified: 4,640 cases, three-engine cross-audit, FP=FN=0
- Conjecture 14.3 verified: 875,658 configurations, FP=FN=0
- V2.3 (Final Polish): honest edition — Conjecture 14.3 correctly labeled [VHC], not [PROVED]
- GitHub repository established as executable verification environment
 
### Milestone 3 — V1.16 (August 2026)
**Boundary Witness Principle — 8-Neighbor Interior Definition**
 
- Established 8-neighbor interior definition (int_8) for self-healing
- Theorem 4.2: 8-Neighbor BWP implies universal self-healing
- Dual-track verification: Mode 1 (empirical subset) + Mode 2 (global BWP check)
- Extended to 3D non-rectangular shapes (triangular prism, square pyramid)
 
### Milestone 2 — V1.12 (August 2026)
**Rectangular Box Self-Healing — First Proved Theorem**
 
- First unconditional proof: h*=2 for rectangular boxes (d≥2)
- Dispersed Corner Decomposition introduced
- d=1 counterexample established (necessity of d≥2)
- Three-engine architecture (pure-set / bitwise / formula) established
 
### Milestone 1 — V1.4 (August 2026)
**Problem Formulation and Initial Computational Exploration**
 
- Self-healing threshold h*(A_hole; A_full) formally defined
- Initial computational experiments: 2D/3D convex lattice regions
- Conjecture M3' first formulated from numerical data
- Multi-block independence problem identified
